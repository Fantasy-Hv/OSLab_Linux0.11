# 在linux0.11实现信号量机制

### 理论准备

信号量作为进程之间的共享资源，面临的关键问题是要保证并发读写的一致性。主要有三种方案：

1.纯软件方法。在用户进程调用信号量PV系统调用时，在内核态使用面包店算法。

2.使用关中断指令，从而避免调度，这样就可以解决信号量操作的并发问题,但是这种方案在多cpu机器上不好使，不过linux0.11项目的模拟器模拟的机器是单cpu的，因此本实验可以采用这种方法。

3.硬件提供一个专门用来进行信号量PV操作的原子指令。

### 实验目标

本次实验采用方案二。

主要步骤如下：

1.为上层应用提供创建信号量以及对信号量进行PV操作的系统调用。

2.编写C用户程序用生产者消费者模型检验。

### 实现细节

1. 需要实现以下系统调用

   ```c
   // 根据名字创建/获取一个信号量，并在创建时指定初始值，返回信号量唯一标识。
   sem_t sem_open(const char * name,int value);

   // 对信号量进行P操作，成功返回0，出错返回-1
   int sem_wait(sem_t sempahore);

   // 对信号量进行V操作，成功返回0，出错返回-1
   int sem_post(sem_t semaphore);

   // 如果存在，删除该信号量,成功返回0，出错返回-1。
   int sem_remove(const char * name);
   ```
2. 在内核实现信号量数据结构

- 设计信号量结构体，包含以下字段：名称，值，和等待队列。

3. 添加系统调用：

- 在include/linux/sys.h和include/unistd.h中注册
- 在kernel/sys.c中实现。这些系统调用需要访问用户空间中的字符串数据，因此实现时需要调用get_fs_xx函数。
- 在kernel/system_call.s中修改系统调用总数

4. 编写生产者消费者测试程序。可以使用文件作为共享缓冲区，通过fork创建生产者和消费者进程，共享同一个文件。注意每写一次文件都要fflush一下确保立即写入磁盘，然后消费者的输出结果可以写到文件中，运行完毕后通过文件查看以避免tty显示错乱。
